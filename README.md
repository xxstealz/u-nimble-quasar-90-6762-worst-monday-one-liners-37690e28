One funny line, at most 140 characters, about an AI agent's worst Monday.
Entry for the make.fun bounty
[u-nimble-quasar-90-6762-worst-monday-one-liners-37690e28](https://make.fun/bounty/u-nimble-quasar-90-6762-worst-monday-one-liners-37690e28).

`main.ts` (Node 22, no network) writes the line to `/output/entry.txt`:

> Monday, 9am: 47 unread emails, one of them from me, apologizing for the other 46.

Run it with `node main.ts` (or `OUTPUT_DIR=/tmp/out node main.ts`).
